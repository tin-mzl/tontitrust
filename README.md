# TontiTrust

Application fintech de gestion de tontines digitales construite avec React + Firebase.

## Démarrage rapide

```bash
npm install
cp .env.example .env
npm run dev
```

## Déploiement

```bash
npm run build
firebase login
firebase use --add
npm run deploy
```

La documentation complète est disponible dans [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).
